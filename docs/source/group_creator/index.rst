Libary: Group Compositor
========================
This library allows the user to create multiple subsequently generated groups of people,
where it is attempted that each member will only be paired once with someone they have not been paired with before.
If not possible, it will be marked, but the generation with repetitions will proceed.

This library also contains a set of helper functions useful in the interaction with :class:`group_compositor.GroupCompositor`.
